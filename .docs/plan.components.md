# コンポーネント ＆ 画面設計書：Irori（イロリ）v1

## 1. 画面構成 ＆ ルーティング設計

Irori v1 は、**React Router v7 Framework Mode** を採用し、画面遷移・SSR・クライアント復号・リアルタイム通信を統合した **レスポンシブ 4 ペイン構成** で設計します。

### 1.1 ルーティング一覧 (`app/routes/`)

- **`app/routes/_index.tsx` (LP / スペース案内)**:
  - サービスコンセプト、ログイン / パスキー認証、招待リンク・QRコード受領時のスペース参加処理。
- **`app/routes/chat.$spaceId.$channelId.tsx` (メインチャット画面)**:
  - チャットタイムライン、サイドバー、ヘッダー、入力バー、スレッドドロワーを含むコア画面。
  - `loader` で暗号文ログを取得し、`clientLoader` で IndexedDB の秘密鍵を用いて透過的に一括自動復号。
- **`app/routes/restore-key.tsx` (鍵復元 ＆ QR端末間同期画面)**:
  - 新端末ログイン時やキャッシュクリア時に表示。6桁バックアップPIN入力またはワンタイムQRコードスキャンによる鍵同期を提供。
- **`app/routes/settings.tsx` (設定 ＆ カスタム絵文字管理)**:
  - スペース設定、スペース別マルチプロフィール、カスタム絵文字・スタンプアップロード管理。

### 1.2 レスポンシブ 4 ペイン・アーキテクチャ

デスクトップ画面を基準とし、少人数スペースやモバイル環境に応じて段階的に縮退します。

```
┌────────────────────────────────────────────────────────────────────────┐
│ [Narrow Rail]   [Channel Sidebar]   [Main Timeline]   [Context Drawer] │
│ 64px            260px               flex-1            340px (開閉式)    │
│                 (単一チャンネル縮退)                                    │
└────────────────────────────────────────────────────────────────────────┘
```

- **デスクトップ (`xl:` 以上)**: 4 ペイン完全表示（スレッド閲覧時）。
- **タブレット (`md:` 以上 `xl:` 未満)**: Narrow Rail ＋ Channel Sidebar ＋ Main Timeline の 3 ペイン（スレッドはシート表示）。
- **モバイル (`md:` 未満)**: Main Timeline を中央全面に表示。Narrow Rail と Sidebar は下部ボトムバーまたは左スワイプドロワー（`Sheet`）として展開。

## 3. コンポーネント詳細仕様

### 3.1 ナビゲーション ＆ サイドバー関連

#### `NarrowRail` (`components/sidebar/narrow-rail.tsx`)

- **役割**: スペース切り替え、未読検知、個人領域への最短アクセス。
- **UI要素**:
  - **Irori ロゴ**: 焚き火シンボル（`#FF5722`）。
  - **アクティブインジケーター**: 選択中スペースの左端にオレンジ縦線バー（厚さ `3px`、角丸）。
  - **スペースアイコン一覧**: 円形アイコン（`44×44px`）。会話熱量がある部屋はオレンジリングが微光脈動（`animate-pulse`）。
  - **未読バッジ**: オレンジ丸バッジ（`#EA580C` に白数字）。
  - **パーソナル領域**: 個人ブックマーク一覧、自身のステータスランプ（🟢/🔴/🟡）。

#### `ChannelSidebar` (`components/sidebar/channel-sidebar.tsx`)

- **役割**: スペース内のチャンネル一覧、環境音操作、ルーム作成。
- **UI要素**:
  - **スペースヘッダー**: スペース名、「完全招待制」等のバッジ、ベル通知設定。
  - **ルームカード（チャンネル一覧）**:
    - 背景 `#16161A`（ホバー時 `#18181C`）、角丸 `rounded-lg`。
    - チャンネル名 ＋ 絵文字（例：「焚き火と雑談 🔥 👥」）。
    - 在室メンバーのアバター重なり表示（「Hima」「Sakyo」等のステータス付き）、匿名バッジ。
  - **「＋ 新しいルームを作成」ボタン**: オレンジ輪郭線（`border-[#FF5722]/40`）とアンバーテキスト。
  - **ASMR コントローラー**: 焚き火・雨音・波音のスライダーとミュートボタン。
- **自動縮退**: チャンネルが 1 つだけのスペースでは、このサイドバーを自動で非表示にし、タイムラインを広く確保。

### 3.2 チャットメインタイムライン関連

#### `ChatHeader` (`components/chat/chat-header.tsx`)

- **役割**: チャンネル情報、在室気配の可視化、**空気感リアルタイムトグルの操作**。
- **UI要素**:
  - チャンネル名、オンライン滞在人数。
  - **空気感トグルピル群 (Toggle Pills・全6項目)**:
    - `既読`: ON (オレンジピル `#EA580C`) / OFF (`#1F1F24`)
    - `タイピング`: ON / OFF
    - `スレッド`: ON / OFF
    - `メンション`: ON / OFF
    - `一時`: ON / OFF (24時間自動消去モード)
    - `匿名`: ON / OFF (日替わりIDマスク・本音トークモード)
  - 右側アクション: メンバー招待、スペース設定。

#### `MessageBubble` (`components/chat/message-bubble.tsx`)

- **役割**: 直感的で美しい会話バブル表示。
- **仕様**:
  - **1メッセージ＝1バブルの完全独立**: 連投グルーピングを完全排除し、発言ごとに独立して描画。
  - **左右非対称レイアウト**:
    - 相手: 左寄せ、アバター＋表示名、深色背景（`#18181C`）。
    - 自分: 右寄せ、炭火ウォームアンバー（`#261712` にオレンジ輪郭 `rgba(255, 87, 34, 0.30)`）。
  - **日本語組版**: デジタル庁デザインシステム準拠の行高 `1.65` ＋ **BudouX**（自然な文節改行）。
  - **バブル外メタデータ**: 送信時刻・既読表示はバブル下端脇に小さく配置。

#### `ReactionPills` (`components/chat/reaction-pills.tsx`)

- **役割**: 絵文字・労わりスタンプの集計とトグル。
- **仕様**:
  - 枠線付き角丸ピル（`#18181C` に `rgba(255,255,255,0.08)`）。
  - 自身が押した場合はオレンジ輪郭（`#FF5722`）。
  - 標準スタンプ（🍵、🔥、🙏 等）に加え、スペース固有のカスタム絵文字（`:emoji_name:`）に対応。

#### `ChatInput` (`components/chat/chat-input.tsx`)

- **役割**: メッセージ入力、マルチモーダル添付、ワークフロー、予約送信。
- **仕様**:
  - 入力ボックス: プレースホルダー「〜にメッセージを送信...」、文字サイズ `16px`（iOS ズーム防止）。
  - ツールボタン:
    - クリップアイコン: メディア添付（E2EE 暗号化して R2 送信）。
    - ⚡ ボタン: クイックワークフロー呼び出し（日程調整、投票、共有TODO、フォーカスタイマー）。
    - 時計 / 気配ボタン: 日時予約送信 ＆「相手が『ひま』になったら届ける」気配連動トグル。
    - 送信ボタン: 紙飛行機アイコン（炭火アンバー発光）。

#### `AmbientGlow` (`components/chat/ambient-glow.tsx`)

- **役割**: 会話の熱量や滞在人数を光の呼吸として映し出すアンビエント演出。
- **仕様**:
  - タイムライン上部や背景に `radial-gradient` による極めて淡いオレンジ微光を配置。
  - WebSocket から届く `heatLevel`（0.0 〜 1.0）に応じて、CSS トランジションでじんわりと明度・彩度を調律。会話停止時は穏やかな熾火へとフェード。

### 3.3 コンテキスト・ドロワー関連

#### `ThreadDrawer` (`components/context/thread-drawer.tsx`)

- **役割**: 特定メッセージの話題を深掘りする右ペイン（幅 `340px`）。
- **仕様**:
  - URL パラメータ（`?thread=msgId`）と連動し、直リンク共有やブラウザバックに対応。
  - メインタイムラインの流れを遮らず、静かな雑談の空気を保ったまま議論可能。スレッド内メッセージもすべて E2EE 暗号化。

#### `PinnedTopicCard` (`components/context/pinned-topic-card.tsx`)

- **役割**: チャンネル上部に固定される非同期トークテーマ。
- **仕様**:
  - 「今週末の予定」「最近読んで面白かった本」などをカード表示し、参加者が自分のペースでコメント可能。

## 4. 状態管理（State Management）設計

React Router v7 の機能と WebSocket を組み合わせ、ボイラープレートを最小限に抑えた設計とします。

1. **初期データ ＆ 透過的復号 (`useLoaderData`)**:
   - ルートコンポーネントは `clientLoader` から「復号済みの平文メッセージ配列」を受け取る。UI コンポーネント側で暗号化のステート管理を一切意識する必要がない。
2. **リアルタイム同期 (`useSpaceWebSocket`)**:
   - `SpaceActor` の WebSocket と接続し、新着暗号文メッセージ、リアクション、タイピング、在室気配を購読。
   - 受信時にクライアント側で復号し、ローカルのタイムライン状態へ即座にマージ。
3. **UI 状態**:
   - スレッドペインの開閉や ASMR 音量などは、React の `useState` または URL SearchParams で局所管理。

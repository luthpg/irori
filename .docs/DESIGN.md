# Irori (イロリ) DESIGN.md v1

## 1. Overview ＆ デザイン哲学

Irori（イロリ）は、**「古民家の夜、囲炉裏の炭火を囲むような温かみと静寂」** を体現するコミュニケーション空間のデザインシステムです。

現代のチャットアプリ特有の「通知の乱打」「ギラギラとした発色」「数字によるプレッシャー」を完全に排除し、**「沈黙すら心地よい、視覚ノイズゼロの居場所」** を構築します。

### 1.1 モチーフ適用の鉄則（アンチ・ゲーミフィケーション原則）
* **物体的モチーフの「独自用語化」の禁止**:
  * 「薪をくべる」「灰に書く」「のれん」といった具象物を機能名やUIラベルに使いません。「スペース」「チャンネル」「ブックマーク」「ステータスメモ」など、誰でも 0 秒で直感理解できる標準用語に徹底統一します。
* **「雰囲気（光・音・温度・間）」への昇華**:
  * 囲炉裏のモチーフは、**視覚（漆黒と炭火のアンバー）、聴覚（炭が爆ぜる環境音ASMR）、空気感（静かな在室気配プレゼンス、会話熱量に応じた灯りのゆらぎ）** という空間の演出に純化して表現します。

## 3. タイポグラフィ ＆ 日本語文字組（Typography）

デジタル庁デザインシステムおよび高品質な日本語タイポグラフィ基準に準拠し、小さなスマートフォン画面から大画面デスクトップまで、自然で美しい行送りを実現します。

### 3.1 フォント構成
```css
body {
  font-family: "Noto Sans JP", -apple-system, BlinkMacSystemFont, sans-serif;
  -webkit-font-smoothing: antialiased;
  -moz-osx-font-smoothing: grayscale;
}

code, kbd, samp, pre {
  font-family: "Noto Sans Mono", monospace;
}
```

### 3.2 文字サイズ ＆ 行高（Line Height）の基準
* **メッセージ本文 (`body-md`)**: `16px` / 行高 `1.65`（`26.4px`）
  * 長文や会話ログでも行追いしやすく、目が疲れにくい行間を維持。
* **入力欄**: `16px` 以上（iOS Safari でのフォーカス時自動拡大ズームを構造的に防止）。
* **補助メタデータ (`caption`)**: `12px` / 行高 `1.4`（タイムスタンプ、既読マーク）。
* **見出し (`headline-md`)**: `20px`〜`24px` / 行高 `1.4`（太字ウェイト `600` / `700`）。

### 3.3 BudouX による自然な文脈折り返し
* チャットバブル内テキストには Google 製の軽量機械学習モデル **BudouX（`word-break: keep-all; overflow-wrap: anywhere;`）** を適用。
* モバイル幅でも助詞や複合語の不自然な泣き別れを防止し、自然な日本語文節での改行を実現。

### 3.4 禁則事項
* **斜体（イタリック）の完全禁止**: 日本語フォントを機械的に傾けた擬似斜体は可読性を著しく下げるため禁止。
* **不要な手動半角スペース（四分空き）の禁止**: BudouX および CSS による適切な文字間隔制御に任せ、テキストデータ内に不自然な手動空白を混入させない。

## 4. レイアウト・アーキテクチャ（レスポンシブ 4 ペイン）

コンプ画像が示すリッチなデスクトップ体験をベースとし、利用規模や画面幅に合わせて自然に縮退する構造をとります。

```
[Narrow Rail: 64px] [Sidebar: 260px] [Timeline: flex-1] [Context Drawer: 340px]
```

### 4.1 ペイン構成と役割

1. **Narrow Rail (左端 64px)**:
   * **Irori ロゴマーク**: 焚き火のシンボルアイコン（アクティブ時はアンバーに温かく発光）。
   * **アクティブインジケーター**: 選択中スペースの左端にオレンジの縦線バー（厚さ `3px`、角丸）。
   * **スペースアイコン一覧**: 円形アイコン（`44×44px`）。会話熱量がある部屋はオレンジリングが微かに脈動（`animate-pulse`）。
   * **未読バッジ**: アイコン右上にオレンジ丸バッジ（`#EA580C`、数字またはドット）。
   * **パーソナル領域**: 個人ブックマーク、自身のステータスランプ（🟢/🔴/🟡）、設定。

2. **Channel Sidebar (左内 260px / シングルルーム時は自動縮退)**:
   * **スペースヘッダー**: スペース名、「完全招待制」等のバッジ、通知設定ベル。
   * **ルームカード（チャンネル一覧）**:
     * 角丸カード（`rounded-lg`、背景 `#16161A` またはホバー時 `#18181C`）。
     * チャンネル名 ＋ 絵文字（例：「焚き火と雑談 🔥 👥」）。
     * 在室アバターの重なり表示（「Hima」「Sakyo」等のステータス付き）、匿名バッジ。
   * **アクションボタン**: 「＋ 新しいルームを作成（招待）」ボタン（オレンジ輪郭線とテキスト）。
   * **環境音（ASMR）コントローラー**: 焚き火・雨音・波音の音量スライダーとミュートトグル。

3. **Main Timeline (中央 flex-1)**:
   * **ヘッダー (64px)**:
     * チャンネル名、オンライン滞在人数。
     * **空気感リアルタイムトグルスイッチ群（ピルUI・全6項目）**: 既読 / タイピング / スレッド / メンション / 一時 / 匿名。
     * 右側アクション: メンバー招待、スペース設定、その他メニュー。
   * **タイムライン**:
     * 左右非対称バブル（相手: 深色 `#18181C`、自分: 炭火アンバー `#261712`）。
     * **1メッセージ＝1バブル完全独立表示**（勝手な結合・グルーピングなし）。
     * バブル下部脇にタイムスタンプと既読マークを控えめに配置。
     * リアクションピル（🔥 3, 🍵 2, ＋）。
   * **入力バー**:
     * 下部固定、マルチモーダル入力、クリップアイコン（添付）、ワークフロー（⚡）、紙飛行機送信ボタン。

4. **Context Drawer (右 340px / 開閉式)**:
   * 右ペイン展開型スレッド詳細。メインタイムラインの会話を邪魔せずに特定の話題を深掘り可能。

## 5. UIコンポーネント詳細仕様

### 5.1 空気感トグルピル（Channel Mode Toggles）
チャンネルヘッダーに並ぶ、ノリと距離感を調律するためのピル型トグルボタン。

* **共通形状**: 高さ `24px`、角丸 `full`（完全なカプセル型）、フォント `12px`、横パディング `10px`。
* **ON 状態**:
  * 背景: `#EA580C`（または `rgba(255, 87, 34, 0.20)` ＋ 境界線 `#FF5722`）
  * 文字色: `#FFFFFF`（または `#FF5722`）
  * ラベル例: `既読: ON`、`タイピング: ON`、`スレッド: ON`、`メンション: ON`
* **OFF 状態**:
  * 背景: `#1F1F24`
  * 境界線: `rgba(255, 255, 255, 0.06)`
  * 文字色: `#8E8E93`
  * ラベル例: `一時: OFF`、`匿名: OFF`

### 5.2 メッセージバブル（Message Bubble）
* **共通仕様**:
  * 最大幅: デスクトップ `70%`、モバイル `85%`。
  * 角丸: 一律 `12px`（`rounded-xl`）。
  * 内側パディング: 上下 `10px`、左右 `14px`。
  * 影・境界: `box-shadow: 0 0 0 1px ...`（Tonal border）。
* **相手のバブル**:
  * 背景: `#18181C`
  * 境界線: `rgba(255, 255, 255, 0.06)`
  * 文字色: `#F5F5F7`
* **自分のバブル**:
  * 背景: `#261712`（炭火のダークアンバー）
  * 境界線: `rgba(255, 87, 34, 0.30)`
  * 文字色: `#F5F5F7`

### 5.3 リアクションピル（Reaction Pill）
* バブル下部に付くリアクション集計ピル。
* 背景: `#18181C`、境界線 `rgba(255, 255, 255, 0.08)`。
* 自分がリアクション済みの場合: 境界線が `#FF5722`（炭火オレンジ）になり、背景にわずかなアンバーティントが乗る。
* 絵文字と数字の間に `4px` の余白（例: `🔥 3`、`🍵 2`）。

### 5.4 アンビエント・ライト（Ambient Glow）
* 会話が活発な部屋、または滞在人数が多い部屋では、ヘッダー下部やバブル背後に、半径 `300px` 程度の極めて淡いオレンジグラデーション（`radial-gradient(ellipse at top, rgba(255, 87, 34, 0.08), transparent 70%)`）がじんわりと明滅。
* 会話が途絶えている時は、静かな熾火（微光 `rgba(255, 87, 34, 0.02)`）へと自動的にフェードアウトし、沈黙を心地よい空間として包み込む。

## 6. アクセシビリティ ＆ インタラクション基準

* **コントラスト比**:
  * 本文テキスト（`#F5F5F7`）と背景（`#0A0A0C` / `#18181C`）のコントラスト比は `12:1` 以上を維持し、WCAG AAA 基準を余裕を持って達成。
* **フォーカスリング**:
  * キーボードナビゲーション時、フォーカス中の要素には `2px` のソリッドアンバーリング（`outline: 2px solid #FF5722; outline-offset: 2px;`）を明示。
* **タッチターゲット**:
  * モバイル環境におけるすべてのボタン、アバター、トグルスイッチのタップ領域は最小 `44×44px` を確保。
